# Personal Portfolio Website

A clean, responsive, beginner-friendly personal portfolio website built with semantic HTML5, custom modern CSS3, and vanilla JavaScript. Designed for first-year Computer Science & Engineering (CSE) students to showcase academic background, coursework, skills, and foundational projects.

## Live Demo
Check out the live website deployed on GitHub Pages:
https://Ronith-hub.github.io/

---

## Key Features
- **Semantic HTML5 Layout**: Accessible document outline using header, nav, main, section, article, and footer.
- **Dark Mode Toggle**: Instant light/dark theme switch with persistent memory using browser localStorage.
- **Smooth Navigation**: One-click scrolling to #about, #skills, #projects, and #contact.
- **Floating "Back to Top" Button**: Appears smoothly as you scroll down for effortless navigation.
- **Categorized Skills**: Honest, organized toolkit (Languages, CS Fundamentals, Developer Tools) without arbitrary percentage bars.
- **3 Featured Projects**: Clear project cards detailing problem statements, technical highlights, and direct GitHub source code links.
- **Fully Responsive**: Mobile-first design that adapts seamlessly to phones, tablets, and desktops.

---

## Technologies Used
- **HTML5**: Semantic document outline and metadata.
- **CSS3**: Flexbox and CSS Grid layouts, CSS variables, transitions, and media queries.
- **JavaScript (ES6+)**: DOM manipulation, event listeners, and LocalStorage API.
- **GitHub Pages**: Free static website hosting and continuous deployment.

## How to View and Run Locally

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/Ronith-hub/portfolio.git
   cd portfolio
   ```

2. **Open in Browser**:
   - Simply double-click the `index.html` file to launch it in any web browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, open the folder in **VS Code** and click **"Go Live"** using the **Live Server** extension.
