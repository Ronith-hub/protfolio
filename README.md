# Jesu Ronith | Personal Developer Portfolio

> A modern, responsive personal developer portfolio website designed for a first-year Computer Science & Engineering undergraduate. Built with semantic HTML5, clean CSS3, and interactive vanilla JavaScript.

---

## 📌 Project Overview
This repository hosts the source code for my personal developer portfolio. As a first-year CSE student at **State Institute of Technology**, I created this website to document my learning journey, showcase foundational programming projects, and provide a single hub for my technical profiles.

- **Institution:** State Institute of Technology

---

## ✨ Features
- **Modern Responsive Design:** Balanced centered layout that adapts seamlessly to phones, tablets, and desktops.
- **Atmospheric Gradient Hero:** Visual hero section highlighting current academic standing and key CTAs.
- **Dark Mode with Memory:** Theme toggle in the navigation bar that saves the user's preference in browser `localStorage`.
- **Smooth Navigation:** In-page anchor links glide smoothly to sections (`#about`, `#skills`, `#projects`, `#contact`).
- **Floating "Back to Top" Button:** Automatically appears when scrolling down past 300px.
- **Honest Skill Stack:** Categorized technical toolsets (C, JavaScript, HTML5, CSS3) without arbitrary percentage bars.
- **Interactive Project Cards:** Rounded 16px cards with direct GitHub source code links.
- **1-Click Email Copy:** Clipboard copy feedback button for easy networking.

---

## 🛠️ Technologies Used
- **Semantic HTML5:** Accessible layout using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Modern CSS3:** CSS custom properties (variables), Flexbox, CSS Grid, and `cubic-bezier` hover transitions.
- **Vanilla JavaScript (ES6+):** DOM manipulation, scroll listener, and `localStorage` API.
- **Typography:** Google Fonts (*Plus Jakarta Sans* for headings/body, *JetBrains Mono* for code tags).

## 🚀 How to View Locally

### Method 1: Direct File Open (Zero Tools Needed)
1. Clone or download this repository to your computer.
2. Locate the `index.html` file in your file explorer.
3. Double-click `index.html` to open it directly in Chrome, Edge, Safari, or Firefox.

### Method 2: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` in the sidebar and choose **"Open with Live Server"**.
4. The page will open automatically at `http://127.0.0.1:5500/`.

---

## 🌐 How to Publish for Free on GitHub Pages

1. Create a new repository on [GitHub](https://github.com) named `my-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings** → **Pages** in your repository.
4. Under **Branch**, select `main` and root (`/`), then click **Save**.
5. Your portfolio will be live at:
   `https://<your-github-username>.github.io/my-portfolio/`
